# JSX
- JSX is not the part of React, we can write React code without JSX
- JSX makes the syntax very easy to read, write and understand
- JSX is not HTML, it is XML like syntax
- It prevents our app from Cross-Site Scripting attacks, it sanitizes the data coming from APIs before rendering it etc
